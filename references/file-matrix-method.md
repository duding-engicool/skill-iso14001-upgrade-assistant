# 体系文件修订映射方法论 + 模板

> 把"2026 要求条款"映射到"企业现有体系文件"，产出可执行的修订清单。配合 scripts/file-framework-compare.py 自动比对。

---

## 一、映射逻辑

2026 要求条款（4–10 的 shall 要求）→ 企业应有的体系文件（手册/程序/作业指导书/记录）。

每个要求条款通常对应：
- **环境管理手册**相应章节（覆盖性描述）
- **程序文件**（过程控制）
- **作业指导书**（具体操作）
- **记录/证据**（运行证据）

## 四、自动比对（file-framework-compare.py）使用

用户上传现有文件框架（Markdown 清单 / Excel / Word）→ 脚本解析条目 → 与内置 2026 要求清单做关键词映射 → 输出差距矩阵（哪些要求有对应、哪些缺失）。

- 支持格式：.md / .xlsx / .docx / .txt
- 输出：差距矩阵（markdown 表格）+ 缺失项高亮
- 映射规则：基于条款关键词（如"环境因素"→6.1.2、"方针"→5.2、"风险"→6.1.4）
- 兜底：无法自动映射的条目，由 Agent 在对话中引导用户人工核对

**注意**：自动比对是"辅助定位"，不能替代人工判断。输出后 Agent 应提示用户逐项确认，尤其"有对应但内容未达 2026 要求"的伪匹配。
