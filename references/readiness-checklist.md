# ISO 14001 升版准备度检查表

> 用于让用户快速自评"我现在离 2026 版还差多远 / 该从哪入手"。可作为差距评估的前置自评，也可作为阶段复盘。
> 基于 FDIS 草案，正式发布后复核。

---

## 使用方式
逐项勾选（✅已具备 / ⚠️部分具备 / ❌缺失），统计成熟度。Agent 根据结果给出切入建议。

---

## A. 领导与组织准备（阶段1）
- [ ] 最高管理者知晓 2026 版主要变化（气候/风险机遇/生命周期）
- [ ] 已指定升版负责人与跨职能小组
- [ ] 升版计划已与认证到期/正式版发布时间对齐
- [ ] 已配置升版所需资源（人力/数据/预算）

## B. 实质性差距（阶段2-3，核心）
- [ ] 已识别"风险和机遇"并建有独立登记册（**6.1.4 新增**，最易漏）
- [ ] 4.1 组织环境分析已纳入气候变化、生物多样性、生态系统健康
- [ ] 4.2 相关方识别已纳入自然相关诉求
- [ ] 4.3 范围说明已体现生命周期控制力边界
- [ ] 6.1.2 环境因素识别已覆盖全生命周期 + 紧急情况
- [ ] 6.1.5 / 6.2 措施与目标已纳入风险机遇维度
- [ ] 8.1 运行控制已延伸至设计、采购、供应链环境要求
- [ ] 9.3.2 管理评审输入已含风险机遇

## C. 文件与措辞（阶段4）
- [ ] 已全局替换 outsourced→external provider
- [ ] 已全局替换 fulfil→meet compliance obligations
- [ ] 文件化信息表述已统一为"available as documented information"
- [ ] 已更新第 3 章术语分组引用（如适用）
- [ ] 已建立文件修订矩阵并分配责任

## D. 实施与验证（阶段5-6）
- [ ] 风险机遇登记册已在实际管理中使用
- [ ] 生命周期控制在设计/采购真正落地
- [ ] 内审已覆盖 2026 新增要求
- [ ] 管理评审已引用风险机遇结果

---

## 成熟度判定（给 Agent）
- **A/B 大量 ❌**：尚在起步，建议先用"文件框架比对"入口做全面差距扫描。
- **B 核心项基本 ✅ 但 C 未做**：实质内容到位，处于文件换版阶段。
- **C/D 基本 ✅**：接近完成，重点做验证与认证准备。

> Agent 据此推荐下一步动作，不替代用户的升级决策。
